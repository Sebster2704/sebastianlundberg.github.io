Från API
till resultat.

Appen använder JavaScript och fetch() för att skicka ett GET-anrop till ett externt valuta-API. API:t returnerar data i JSON-format med växelkurs och kursdatum.

Användarens val av valuta bestämmer vilket API-anrop som görs. Datan används sedan för att beräkna och visa det konverterade beloppet direkt på sidan.
