Hur fungerar
mashupen?

API 1 — Alpha Vantage

Alpha Vantage används i konceptet för att hämta finansiell marknadsdata, exempelvis priset på en amerikansk aktie.

Data: aktiekurs i USD
+

API 2 — Frankfurter

Frankfurter används för att hämta valutadata. Här används växelkursen mellan amerikanska dollar och svenska kronor.

Data: USD → SEK

DEN GEMENSAMMA LÖSNINGEN

Från två datakällor
till ett resultat.

Alpha Vantage ger aktiekursen i USD medan Frankfurter ger valutakursen mellan USD och SEK.

Genom att kombinera informationen kan tjänsten beräkna vad ett amerikanskt aktieinnehav motsvarar i svenska kronor.
