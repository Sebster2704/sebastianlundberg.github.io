DEN GEMENSAMMA LÖSNINGEN

Resedata från
två datakällor.

När användaren väljer ett resmål används Open-Meteo för att hämta aktuell temperatur och Frankfurter för att hämta destinationens valutakurs mot SEK.

Informationen kombineras i Resekollen så att användaren på samma plats kan se både vädret på destinationen och vad en resebudget motsvarar i svenska kronor.

OPEN-METEO → VÄDER PÅ RESMÅLET
+
FRANKFURTER → LOKAL VALUTA / SEK
↓
RESEKOLLEN → VÄDER + BUDGET I SEK

Om mashupen: Informationen ovan hämtas från två separata API:er. Open-Meteo levererar väderdata och Frankfurter levererar valutadata. JavaScript kombinerar datan och presenterar resultatet i samma tjänst.
